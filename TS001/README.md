# 🎓 ระบบ E-Portfolio สำหรับข้าราชการครู (Teacher E-Portfolio & Performance Appraisal App)

เว็บแอปพลิเคชัน E-Portfolio สมบูรณ์แบบสำหรับข้าราชการครู เพื่อใช้ในการจัดเก็บรวบรวมผลงาน นวัตกรรม และให้คณะกรรมการเข้ามาตรวจประเมินผลออนไลน์ (รองรับการประเมิน วPA, ครูผู้ช่วย, วิทยฐานะ) ออกแบบ Responsive สวยงาม ใช้งานได้บนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน

---

## 🌟 จุดเด่นและฟังก์ชันหลักของระบบ (Features)

### 1. ระบบ 2 บทบาทผู้ใช้งาน (User Roles)
- **โหมดคณะกรรมการ (Viewer Mode)**: คณะกรรมการสามารถเข้าชมเอกสารทั้งหมด ค้นหา กรองข้อมูล คลิกดูตัวอย่างไฟล์ PDF และดูคลิปวิดีโอ วPA ได้ทันทีโดยไม่มีปุ่มแก้ไขมารบกวน
- **โหมดผู้ดูแลระบบ (Admin Mode)**: ปลดล็อกด้วยรหัส PIN (ค่าเริ่มต้น: `1234`) สามารถ เพิ่ม/ลบ/แก้ไข ข้อมูล, แก้ไขข้อมูลส่วนตัว, เปลี่ยนรูปโปรไฟล์, ใส่ลิงก์ PDF/Google Drive, เปลี่ยนรหัส PIN, และกด **เปิด/ปิด การมองเห็น (Visibility Toggle)** ได้ในคลิกเดียว

### 2. โครงสร้าง 8 เมนูหลักครบถ้วนตามเกณฑ์การประเมิน
1. **หน้าแรก (Dashboard)**: แสดงการ์ดโปรไฟล์, วิสัยทัศน์/คติประจำใจ, สรุปสถิติผลงาน, แถบความคืบหน้า, และปุ่ม Quick Links ไปยังทุกหมวด
2. **ประวัติส่วนตัว (Profile)**: ข้อมูลส่วนตัว, ประวัติการศึกษา, ประวัติการรับราชการ, และตารางภาระงานสอน
3. **การประเมินครูผู้ช่วย (Intensive Preparation)**: แบ่งแท็บ 4 ครั้ง (ครั้งที่ 1-4) ครอบคลุมทั้งด้านการปฏิบัติตนและด้านการปฏิบัติงาน
4. **การประเมิน วPA (Performance Agreement)**: กรองตามปีงบประมาณ แสดงข้อตกลงพัฒนางาน, ประเด็นท้าทาย (Challenge Issue), เครื่องเล่นวิดีโอ YouTube คลิปการสอน, และเอกสารแบบ วPA 1/ส, 2/ส, 3/ส
5. **แผนการจัดการเรียนรู้ (Lesson Plans)**: ชั้นหนังสือดิจิทัล (Digital Bookshelf) แสดงหน้าปกแผนการสอนและสื่อการสอน
6. **เอกสารทางราชการ (Official Documents)**: คำสั่งโรงเรียน, เกียรติบัตร/วุฒิบัตร, ตารางสอน, บันทึกข้อความ
7. **ผลงานและรางวัลที่ภูมิใจ (Achievements & Awards)**: แยกแท็บผลงานครูผู้สอนและผลงานนักเรียน พร้อมเหรียญรางวัลและระดับการแข่งขัน (ระดับชาติ/ระดับภาค/ระดับเขต)
8. **ภาพกิจกรรมต่าง ๆ (Activity Gallery)**: อัลบั้มภาพกิจกรรมพร้อมคำบรรยาย วันที่ และระบบ Lightbox ขยายดูภาพ

### 3. ฟังก์ชันพิเศษ
- **Thumbnail-to-Document (ระบบชั้นหนังสือดิจิทัล)**: หน้าปกหนังสือ 3D Shadow เมื่อคลิกจะเปิดพรีวิว PDF ทันทีในตัวโปรแกรม หรือคลิกเปิดใน Google Drive / แถบใหม่ได้
- **Search & Filter System**: ค้นหาข้อมูลแบบ Real-time และตัวกรองตามปีการศึกษาและหมวดหมู่
- **ระบบสำรองและกู้คืนข้อมูล (Backup & Restore)**: Export/Import ไฟล์ `.json` ได้ ไม่ต้องกลัวข้อมูลสูญหาย

## 🚀 วิธีการนำขึ้นระบบ Vercel (Deploy to vercel.app)

ไฟล์ในโฟลเดอร์นี้ได้รับการตั้งค่า `vercel.json` เรียบร้อยแล้ว สามารถนำขึ้น Vercel ได้ฟรีทันที 2 วิธีดังนี้:

### วิธีที่ 1: ผ่าน GitHub (แนะนำ สะดวกที่สุด อัปเดตอัตโนมัติ)
1. นำโฟลเดอร์นี้อัปโหลดขึ้น GitHub Repository ของคุณครู
2. เข้าเว็บไซต์ [https://vercel.com](https://vercel.com) แล้ว Login
3. กดปุ่ม **"Add New..."** -> เลือก **"Project"**
4. เลือก Repository ที่เพิ่งอัปโหลด แล้วกด **"Import"**
5. ในหน้าตั้งค่า ไม่ต้องแก้ไขอะไร (Framework Preset: Other) แล้วกดปุ่ม **"Deploy"**
6. ภายใน 10-20 วินาที จะได้รับลิงก์เว็บไซต์ เช่น `https://kru-portfolio.vercel.app` นำไปส่งให้คณะกรรมการได้ทันที!

### วิธีที่ 2: ผ่าน Vercel CLI (คำสั่งในเครื่อง)
1. เปิด Terminal / PowerShell ที่โฟลเดอร์นี้
2. ติดตั้ง Vercel CLI (หากมี Node.js):
   ```bash
   npm i -g vercel
   ```
3. พิมพ์คำสั่ง:
   ```bash
   vercel
   ```
4. ทำตามขั้นตอนบนหน้าจอ ล็อกอิน แล้วระบบจะ Deploy ให้ทันที
